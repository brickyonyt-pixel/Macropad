Development Journal

Project Start:
I started this project as a Hack Club Stardance project to design and build my own macropad. I wanted to make a small custom keyboard with my own PCB, CAD and firmware.

Initial Design:
I started with the overall macropad layout and decided where the keys and other components would go. I also started working on the PCB design and the physical enclosure.

PCB Design:
I worked on the schematic and PCB layout, ensuring the components were connected correctly and that the board layout matched the physical design.

CAD:
I designed the physical parts of the macropad and checked that the enclosure and PCB would fit together. I later prepared the CAD files for manufacturing and made sure the final files were available in STEP format.

Firmware:
I worked on the firmware needed to make the macropad function as an input device.

Testing and Changes:
During the project I checked the different parts of the design and made changes where necessary. I also checked that the PCB, CAD and firmware worked together as one project.

Preparing for Production:
After finishing the main design, I organised the files needed to manufacture and build the macropad. This included the PCB Gerber files, CAD files, firmware and bill of materials.

Finalising the Project:
I organised the GitHub repository so that the important project files are easier to find. I also added documentation and pictures of the PCB and CAD to the README.

Stardance Submission:
I prepared the project for Stardance review and went through the repository requirements. I added the remaining documentation and production files so the project could be properly reviewed and reproduced.

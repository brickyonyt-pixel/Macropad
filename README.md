Macropad

A custom macropad project made as part of my Hack Club Stardance project.

About

This is a custom macropad designed to be a small programmable keyboard for shortcuts and macros. The project includes the PCB, CAD, firmware and files needed to produce the macropad.

PCB

The macropad uses a custom PCB designed for the project. The PCB contains the electronics needed to connect the keys and controller and communicate with a computer.
